# Contributing

Everyone is welcome to improve fh2wheel: bug reports, wheel test reports, code, documentation.

## Reporting a wheel or a bug

Open an issue with:

- your wheel, pedals and wheel software (with versions);
- what you did and what happened;
- `data\logs\fh2wheel.log`, ideally with **Detailed log (trace)** ticked in `fh2wheel-config.exe`.

Reports from wheels other than the Moza R9 are especially useful.

## Building

Linux or WSL with `mingw-w64`, `gcc`, `make` and `python3`:

```
make check          # build + unit tests (+ Windows tests when Windows is reachable)
make release        # release zip in build/
```

On Windows, `scripts\test-windows.ps1` runs the tests that need Windows, and
`scripts\install.ps1 -Azimuth <folder>` / `scripts\uninstall.ps1 -Azimuth <folder>` copy or remove the
built files next to `azimuth.exe`.

## Code layout

| Path | Content |
|---|---|
| `dll/src/` | `fh2wheel.dll`: hooks, virtual wheel, force feedback interpreter, DirectInput |
| `dll/src/targets.h` | every address, interface id and slot number taken from the game |
| `proxy/` | `D3DCOMPILER_47.dll` loader (forwarders generated by `tools/gen_proxy.py`) |
| `ui/src/` | `fh2wheel-config.exe` |
| `probe/src/` | `fh2wheel-probe.exe` |
| `tests/unit/` | tests that run anywhere; `tests/windows/` tests that need Windows |
| `docs/HOW-IT-WORKS.md` | how the game's wheel support works and how fh2wheel plugs into it |

## Guidelines

- `make check` must pass before every commit; new or fixed code comes with a test.
- Keep the code free of comments: names should explain it. Explanations go into `docs/`.
- Magic values (addresses, slot numbers, sizes) are named constants, gathered in one place per module.
- Never patch the game blindly: check the game fingerprint and the expected bytes first, and log
  `SKIPPED -- <reason>` when they do not match.
- Do not commit binaries, game files or emulator files.

## Pull requests

Small, focused pull requests are easiest to review. Describe what you changed, how you tested it, and on
which wheel if it touches input or force feedback.
